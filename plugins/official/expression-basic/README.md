# @mumu/expression-basic

**是什么**：基础表情（`emo`）与动作（`act`）词汇，每个词带「什么时候用」的提示；以及教发言者怎么放标记的段落。另教 `<|br|>` 分段。

**为什么 v1 效果差**：十个词、没有提示、教学说「一句话最多一两个」，模型只在开头放一个「开心」。现在词汇带场景、教学讲放置位置（情绪变化那一刻、紧贴那句话），一条回复 1～3 个。

**暴露什么**

- marker 词汇（内核 `io.markers`），其他插件可以再加同名或新词。
- 段落 `expression-teaching`（受众 `performer`）：从词汇表渲染，所有插件贡献的词自动纳入、去重。

**词怎么演不归这里管**：把词映射到 Live2D 表情文件、参数姿态或动作，是 `apps/web/public/live2d/models/<id>/profile.json` 的事。词汇表归插件，映射表归模型。

**怎么改它**

- 加词：改 `BASE`，或在别的插件里 `ctx.io.markers.add({ track, value, hint })`。
- 改教学措辞：改 `render()`；`perReply` 可配。
- 新通道（如 `voice:轻声`）：直接加词，教学会自动多一行；表现端不认识的通道会被忽略。
