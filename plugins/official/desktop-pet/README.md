# @mumu/desktop-pet

**是什么**：她电脑桌面上 Live2D 桌宠（[apps/desktop](../../../apps/desktop/README.md)）的设置与状态：显示开关（默认关）、置顶、宽高、贴哪个角。

**暴露什么**

| 东西 | 说明 |
|---|---|
| 配置 `plugins.desktop-pet.*` | 唯一的一份设置，存在配置库里：重启、换设备都是上次的选择。网页「设置」里的表单由清单 `mumu.ui` 自动生成（显示桌宠 · 置顶 · 宽 · 高 · 位置） |
| 命令 `/pet on` · `/pet off` · `/pet` | 开 / 关 / 看当前开关和桌宠程序在不在 |
| `GET /api/desktop-pet/state` | 经 `web/route` 认领。返回 `{ visible, alwaysOnTop, width, height, corner, alive, shown }`。桌宠程序每 3 秒带 `?from=pet&shown=0\|1` 来取——这就是心跳；网页角色栏按钮也 3 秒轮询一次（不带 `from`，不算心跳） |
| `web/meta` → `pet: { visible }` | 兼容早先的桌宠与客户端 |
| `web/status` → 「桌宠」卡片 | 此刻显示着还是隐藏着、开关是什么、桌宠程序在不在（10 秒没心跳算不在）、最后心跳几秒前、大小位置置顶 |

**为什么设置放后端**：开关有好几处（网页按钮、「设置」表单、桌宠托盘菜单、命令），都改同一份配置，就不会各说各的。
桌宠连不上后端时用自己本地记住的上次状态。

**大小和位置**：桌宠只在这里的宽高或「位置」**变了**时才应用；她手动拖动、拉伸后就记在桌宠本地，不会被拽回去。

**心跳为什么只记在闭包里**：它是「此刻」的事实，不值得落库；配置一改本插件会重载、心跳清零，几秒内桌宠就会再报到
（这段时间状态卡显示「刚重载，等桌宠程序报到」）。

**怎么改它**：默认值改 `package.json` 的 `mumu.defaults`；不想要网页按钮就停用本插件（接口 404 时按钮不出现，
桌宠按本地记住的状态，托盘里照样能开关）。
