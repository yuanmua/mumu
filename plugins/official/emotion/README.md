# @mumu/emotion

**是什么**：角色的情绪状态。两个维度（愉悦度 valence、兴奋度 arousal）随对话演化、随时间回落，不是每次回复从零开始。

**它怎么动**

| 来源 | 影响 |
|---|---|
| 自己说出的 `<|emo:词|>` | 按词表把状态推向该情绪（权重 0.6）。自己说出口的最可信 |
| 对方来消息 | 兴奋度至少提到 0.5 |
| 被打断 | 愉悦度略降 |
| 每 20 秒 | 向基线回落；十分钟没人说话就慢慢变困 |

**暴露什么**

- 服务 `emotion`：`state()`、`nudge(dv, da, why)`（其他插件推一把）。
- 段落 `emotion-now`（受众 `performer`）：「此刻的心情：…」。
- `beat/gather` 材料块：导演看得到角色状态。
- 日志事件 `emotion.changed`：标签变了才记。舞台用它调整待机表情基线。

**怎么改它**

- 基线性格：`baseline`（开朗的角色 valence 高，冷淡的低）。
- 词表 `WORDS`：新表情词在这里补一行；没补的词不影响状态。
- 想让对方的话也影响情绪（被骂会难过）：加一个便宜模型角色 `emotion.read` 给 `percept.received` 打分，再 `move`。刻意没做，先看自表达够不够。
