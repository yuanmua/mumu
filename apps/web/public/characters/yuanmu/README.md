# 原木（Yuanmu）的立绘

这个目录是原木的舞台档案：`profile.json` 把表情 / 动作词映射到这里的图。**图需要你放进来**，放齐之前舞台会显示一块说明卡，聊天不受影响。
设定图（`reference.png`）也放这里，方便对照；它不被程序读取。

## 文件清单

| 文件 | 对应设定图哪一格 | 必需 | 用途 |
|---|---|---|---|
| `base.png` | 第 1 格 · 平静微笑 | **是** | 底图：闭嘴、平静微笑；待机、「平静」、以及所有没有专属图的词都用它 |
| `open.png` | 第 2 格 · 开心 | 否 | 「开心」、心情好时的基线 |
| `laugh.png` | 第 3 格 · 闭眼笑 | 否 | 「大笑」 |
| `blush.png` | 第 4 格 · 害羞 / 脸红 | 否 | 「害羞」「脸红」「心动」「撒娇」「捂脸」 |
| `surprised.png` | 第 5 格 · 惊讶 | 否 | 「惊讶」、被打断那一下 |
| `smug.png` | 第 6 格 · 得意 / 调皮 | 否 | 「得意」 |
| `eyes-closed.png` | 第 1 格的闭眼版 | 否 | 眨眼（随机 2–6 秒闭 120ms）。可以是整图，也可以只画眼睛区域、其余透明 |
| `mouth-open.png` | 第 1 格的张嘴版 | 否 | 口型（按语音音量 / 字幕节奏交叉淡入）。同上，可只画嘴部。没有它就用轻微点头代替 |

缺哪张，那个词就停在上一张图上，动作照做；缺 `base.png` 舞台整个变成说明卡。

## 硬要求

- **透明背景 PNG**，建议 **1200×2000**（竖构图），全身、正面、脚在画面底部。
- **所有图同一姿势、同一构图、同一画幅，逐像素对齐，只改脸**。立绘靠整图淡入淡出换表情，没对齐切换时就会跳。
  最稳的做法：先画 `base.png`，其他图都从它改脸（图生图 / 局部重绘），不要重新生成整张。
- 身体没有被截断：杖、书、裙摆都在画面内（舞台会做 1–2% 的呼吸缩放与轻微摆动）。

其余图在底图基础上**只改脸**（图生图，保持姿势与构图）：

| 文件 | 追加的提示 |
|---|---|

| `blush.png` | 害羞，脸颊泛红，视线稍微偏开，嘴微抿 |
| `surprised.png` | 惊讶，眼睛睁大，嘴微张成小 o 形 |
| `smug.png` | 得意、调皮，一边嘴角上扬，眼神狡黠 |

负面提示：背景、文字、水印、多人、裁切、姿势变化、手部变形。

## 换个角色也能用

把这套目录结构复制一份、改 `profile.json` 里的文件名与词映射，再在 `plugins/official/characters/characters/<id>/character.json` 里指向它。档案格式见 `apps/web/README.md`「舞台实现」。
