# scripts/

开发与运维脚本。各脚本用法见文件头；这里只说几个需要额外说明的。

`chat-replay.ts` 是私聊回放：把一段对话里对方的话按原节奏重发到新测试频道，跑完用 bench 的逐条 + 整段裁判打分，调回复策略时做改前改后对比；
`chat-scripts/*.tsv` 是配套的私聊剧本（每行「秒数<TAB>文本」）：碎句连发后问正事、要想的问题、表情包刷屏、说一半换话题、深夜一句。
测试一律对着单独的本地测试实例跑（`MUMU_URL=http://127.0.0.1:3940`），不碰正在服务真 QQ 的那份。

## Windows 上常驻

| 脚本 | 作用 |
|---|---|
| `win-install-task.ps1` | 注册任务计划「Mumu」：登录时在桌面会话里跑 `win-start.ps1` |
| `win-start.ps1` | 守护循环：`npm start`，崩了 5 秒后拉起，日志在 `data\logs` |

两个脚本默认项目在 `C:\mumu`，放在别处就改脚本里的路径。网页没有鉴权，本体用普通权限跑就够。
